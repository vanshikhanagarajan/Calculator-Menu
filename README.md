# Python Calculator Menu

## Description
A simple menu-driven calculator program built using Python. It allows users to perform basic arithmetic operations such as addition, subtraction, multiplication, and division through an easy-to-use menu.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Menu-driven interface
- User input handling

## Technologies Used
- Python

## How to Run
1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program using:

```bash
python calculator.py
```
